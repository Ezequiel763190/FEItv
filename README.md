FEItv

O FEItv é um projeto desenvolvido totalmente em Python com a proposta de simular o funcionamento básico de plataformas de streaming, como Netflix e YouTube.

A ideia principal do projeto foi criar um sistema interativo no terminal onde o usuário consegue criar uma conta, fazer login e acessar diferentes funções relacionadas a filmes e listas pessoais.

Objetivo do projeto:

Esse projeto foi desenvolvido como forma de praticar e aprimorar conhecimentos em Python e lógica de programação. Durante o desenvolvimento foram utilizados conceitos como:

- Estruturas condicionais,
- Laços de repetição,
- Funções,
- Arquivos.txt,
- Manipulação de dados,
- Organização de menus interativos,
- Sistema de autenticação de usuários,

Funcionalidades:

- Cadastro de Usuários,
- Login na Plataforma,
- Logout/ sair da conta,
- Buscar Filmes,
- Descurtir Filmes,
- Criar Lista de Favoritos,
- Adicionar Filmes a Lista,
- Visualizar Filmes Favoritos ( Nos arquivos.txt ),
- Excluir Lista de Favoritos,

Tecnologias:

- Python,
- Terminal / Console,
- Lógica de Programação,

Sobre o Projeto: 

O FEItv foi criado com foco em aprendizado e prática. O objetivo não foi apenas fazer um sistema funcionar, mas também melhorar a organização do código, a construção da lógica e a experiência do usuário dentro do terminal. Esse projeto foi desenvolvido durante o primeiro semestre do meu curso na Centro Universitário FEI como parte das atividades práticas da graduação, aplicando conceitos fundamentais de programação aprendidos em aula. Além disso, o projeto ajudou no desenvolvimento de habilidades importantes em Python, principalmente na criação de sistemas interativos, organização de código e manipulação de estruturas de dados.
